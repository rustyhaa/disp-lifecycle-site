# 처분 정책 시뮬레이터 (시연용)

상품을 하나씩 결정하는 도구가 아니라, 처분 할인 규칙(정책)을 바꿔 보고 그 결과를 미리 보는 정적 사이트입니다.

- `easy.html` **한눈에 보기**(설정값 없는 현업용): 결론을 문장으로 보여 줌. 문장마다 가정 65가지 등급(초록·노랑·회색)
- `policy.html` **정책 설계**(기본 손잡이 3개 + 자세히): ① 대표 상품 워크스루 ② 상품 요약(실제 경과 대비 차이) ③ 민감도 ④ 예외 리포트. 왼쪽 "자세히 설정"에 2단계 조건과 가정
- `guide.html` **설명**(사용설명서): 화면 읽는 법, 정책 설계 쓰는 법, 용어 풀이, 자주 묻는 질문
- 하위 화면(탭이 아니라 설명·더 보기에서 연결):
  - `index.html` **입력 확인**: 정책 2단계 조건에 쓰이는 배수 확인
  - `lifecycle.html` **상품 생애주기**: 시간축 위에 정책 단계 전환 시점을 얹음. 맨 위 "재고 출처" 요약과 상세는 발주종료 잔고가 어느 입고에서 왔고 결국 무엇이 됐는지(입고 추정 + FIFO 가정) 보여 줌
  - `story.html` **설계 이야기**: 왜 상품별 결정 대신 정책 설계인가, 버린 길, 모델과 가정, 주장하지 않는 것
- `policy.js` 정책 계산 모델, `source.js` 재고 출처 모델(화면 공용), `tests/` 숫자 검사(`node tests/policy.test.js`, `node tests/source.test.js`, `tests/robust.test.js`)
- 데이터: `lifecycle.json`(상품 30개), `data.json`(처분 15건). 둘 다 같은 가상 상품에서 만든 **시연용 가상 데이터이며 실제 상품·수치와 무관**합니다. 단계 코드·처분유형·기준값도 가상 설정입니다.

## 모델 요약
- 기본 수요 = 실제 판매 ÷ 반응 가정 배율. **품절 주 보정**: 재고 0 또는 재고 자료 없음 주는 판매가 잘린 주이므로 역산에서 빼고, 양옆에서 가장 가까운 정상 주 2개씩의 평균으로 메웁니다(한쪽만 있으면 그쪽만).
- 정책: 발주종료 뒤 남은 재고가 X주 치 초과 → 1단계 할인, N주 관찰 배수 < Y → 2단계, 1단계 뒤 Z주 미소진 → 종료 심사.
- 손실 = 할인액 + 남은 재고 원가 × 처리 손실률. 실제 경과에도 같은 식을 써서 **차이**만 의미 있게 읽습니다.
- 반응 가정(할인 30%·50%일 때 판매 배율)과 처리 손실률은 가정이며 화면에서 조정·민감도로 봅니다.
- 재고 출처: 입고 = max(0, 이번 주 재고 − 지난주 재고 + 이번 주 판매). 재고 자료가 없는 주는 추정 불가 구간으로 두고 메우지 않음. 종료 직전 입고 기준(6주 이내, 주평균 판매 4주 치 이상)은 가상 설정. FIFO는 가정이며 평균 소진과 비교.
